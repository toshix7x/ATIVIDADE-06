# ATIVIDADE-06
## O que é Git?

Git é um sistema de controle de versão distribuído utilizado para rastrear alterações em arquivos e projetos de software.

Com o Git é possível:

- Controlar versões do código;
- Trabalhar em equipe;
- Recuperar versões anteriores;
- Criar ramificações (branches);
- Registrar alterações no projeto;
- Organizar o desenvolvimento.

---

# O que é GitHub?

GitHub é uma plataforma online que hospeda repositórios Git.

Ele permite:

- Armazenar projetos na nuvem;
- Compartilhar código;
- Trabalhar colaborativamente;
- Gerenciar tarefas;
- Automatizar processos;
- Criar documentação;
- Publicar projetos online.
